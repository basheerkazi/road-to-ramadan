# Road to Ramadan

By **Basheer Kazi** · Growth with Purpose

A free, private daily planner for the weeks before Ramadan. Everything stays on the user's device.

Live: https://basheerkazi.github.io/road-to-ramadan/

## Install as an app
- **Android (Chrome):** open the link, then tap **Install** in Settings, or the browser menu > **Install app**.
- **iPhone (Safari):** tap **Share** > **Add to Home Screen**.
- **Windows or Mac (Chrome or Edge):** click the install icon in the address bar, or Settings > **Install**.
